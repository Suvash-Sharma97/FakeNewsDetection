# Fake News Detection System

This project is a full-stack Fake News Detection web application that utilizes machine learning to classify news articles as real or fake. The frontend is built using Vite and React, while the backend is powered by Flask and serves a deep learning model trained with TensorFlow/Keras.

## Features

- Input a news headline or article and receive a prediction on its authenticity.
- Interactive and responsive frontend built with Vite + React.
- Backend API developed using Flask to serve predictions.
- Model trained using deep learning (TensorFlow/Keras).
- Git LFS used to manage large model files.

## Tech Stack

- **Frontend**: Vite, React, JavaScript
- **Backend**: Flask, Python
- **Machine Learning**: TensorFlow, Keras
- **Deployment**: GitHub, Git LFS
